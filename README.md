# Notification Engine - Enterprise Control Plane 🚀

A high-throughput, multi-channel notification management platform built with a robust Node.js, Express, Redis, and BullMQ backend, coupled with a modern React, Vite, and Tailwind CSS admin dashboard.

## 📁 Repository Structure
- **/backend**: Node.js microservices backend handling REST APIs, WebSocket real-time events, Redis caching, and BullMQ background queue dispatch pipelines.
- **/frontend**: Vite + React admin control plane featuring live terminal logs, notification sandbox, template management, DLQ diagnostics, and Cmd+K global search.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), Redis, BullMQ, Socket.io, JWT Authentication.
- **Frontend:** React, Vite, Tailwind CSS, Recharts, Lucide React, Socket.io-client, pnpm.

## ⚙️ Quick Start

   \`\`\`bash
   git clone https://github.com/Visun517/notification-backup.git
